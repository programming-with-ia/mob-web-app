# Dedicated Browser App

This is a React Native Expo application that acts as a dedicated browser for a single website.

## Configuration

The target URL and injected JavaScript can be configured in `src/config.ts`.

## Customizing the Splash Screen

To customize the splash screen, replace the `splash.png` file in the `assets` directory with your own image. The recommended size for the splash screen image is 1284x2778 pixels. After replacing the image, you may need to update the `splash` section of the `app.json` file to reflect the new image path.
